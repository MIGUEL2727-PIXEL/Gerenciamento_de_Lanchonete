# 🍔 Sistema de Gerenciamento de Lanchonete

Sistema web desenvolvido para auxiliar lanchonetes de pequeno e médio porte no controle e organização de pedidos e operações diárias.

## 🚀 Tecnologias Utilizadas
* **Front-end:** HTML5, CSS3 e JavaScript
* **Back-end:** Node.js (`server.js` e `database.js`)
* **Banco de Dados:** SQL (modelado e gerenciado via MySQL Workbench)

## 📂 Estrutura do Projeto
* `public/` — Arquivos da interface visual (páginas HTML, estilos e scripts do cliente).
* `Codigo Sql da lanchonete/` — Script SQL (`fastfood.sql`) com a estrutura das tabelas do banco de dados.
* `server.js` — Configuração do servidor da aplicação.
* `database.js` — Conexão e integração entre o sistema e o banco de dados.
